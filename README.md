## ☁️ Ketersediaan Data Cuaca BMKG 

Welcome to the **BMKG Weather Data Availability App**!  
This Streamlit application provides access to **daily and monthly data availability** from BMKG, including:  

- 🌤 **METAR** (Meteorological Aerodrome Reports)  
- 🎈 **RASON** (Radiosonde observations)  
- 🛫 **SPECI** (Special Aerodrome Reports)  
- ✈️ **TAF** (Terminal Aerodrome Forecasts)  

👉 Try the live app here: [Ketersediaan Data BMKG](https://ketersediaan-data-bmkg.streamlit.app/)  

---

## ✨ Features  
- 📅 **Daily & Monthly Data Availability** displayed in clean, interactive tables.  
- 📊 **Visualizations** to better understand the availability trends of different datasets.  
- 🔍 Easy-to-use interface powered by **Streamlit**.
